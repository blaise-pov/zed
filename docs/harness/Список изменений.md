### Профили и права доступа агентов
- **Настраиваемые профили агентов.** Профиль содержит собственные инструкции, права инструментов и фильтры навыков. Система применяет профиль при запуске субагента. Параметр `profile` добавлен в инструмент `spawn_agent`.
- **Рекурсивный запуск субагентов.** Субагент порождает субагентов. Настройки вложенности управляют глубиной. Флот делегирует задачи по профилям.
- **Разграничение записи (write scopes).** Профиль объявляет разрешённые пути записи. Система проверяет области записи перед запуском субагента и отклоняет нарушение. Инструменты файлов и терминал работают только внутри выделенного worktree.
- **Профили уровня проекта.** Настройки проекта переопределяют пользовательские профили. Файлы проекта сливаются с переопределением одноимённых ключей.
- **Запрет по умолчанию (default-deny) для навыков.** Профиль разрешает только явно указанные навыки.

### Task Graph Service (TGS)
- **Интеграция с графом задач через MCP.** Добавлен провайдер задач для MCP-сервера TaskGraph. Панель агента создаёт, переименовывает, архивирует и удаляет задачи и цели.
- **Событийное хранилище задач.** Хранилище обновляется по событиям, без опроса. Флаг «грязных» данных управляет перезагрузкой.
- **Пакетное создание задач с зависимостями.** Одна транзакция создаёт набор задач. Зависимости `depends_on` связывают задачи. Создание задачи требует `goal_id`.
- **Метрики задач.** Панель показывает длительность, расход токенов и модель. Метрики отображаются во всплывающей подсказке.

### Изоляция рабочих деревьев (task worktrees)
- **Реестр и жизненный цикл task worktree.** Система создаёт worktree для задачи и освобождает слот после завершения. Отмена хода гарантирует освобождение слота.
- **Матрица изоляции запуска.** Worktree создаётся только при `task_id` с параметром ветки. Режим `worktree_of` даёт субагенту общее дерево без права коммита.
- **Изоляция нескольких репозиториев.** Подсказка репозитория (`repo_hint`) выбирает корень для worktree. Возобновление потока восстанавливает правильное дерево.
- **Изоляция окружения.** Файл `.env` изолирован по `WorktreeId`. Переменные `$VAR` раскрываются в настройках. Языковые серверы отключаются для служебных деревьев.

### Парковка при ограничениях API
- **Политика парковки при rate limit.** Система приостанавливает запрос при ответе 429. Система возобновляет запрос после сброса лимита. Интервал опроса адаптируется под время сброса.
- **Парковка ошибок соединения и шлюза.** Ошибки сети и апстрима паркуются как лимиты. Кнопка повтора запускает запрос немедленно.

### UI: панель задач агента
- **Панель задач агента (Agent Task Panel).** Панель показывает цели, задачи и субагентов. Группы целей свёртываются. Панель имеет отдельную настройку дока.
- **Карточки субагентов.** Карточка показывает профиль, модель и метку ветки. Карточка раскрывает ошибки субагента и ошибки запуска. Выбор модели синхронизируется с задачей.
- **Управление списком.** Фильтры статуса, архивация и удаление доступны из панели. Строки потоков показывают агента, модель и ветку. Статистика diff сохраняется и отображается.

### Терминал
- **Терминальный сторожевой таймер (watchdog).** Терминал отслеживает активность вывода и PID оболочки. Таймер завершает зависшую команду. Повтор команды не вызывает ложного срабатывания.
- **Терминальная политика.** Команды git проходят по белому списку только для чтения. Обёртка терминала проверяет бюджет делегирования.

### Промпты и флот агентов
- **Файловые промпты с шаблонами.** Промпты профилей хранятся в файлах. Директива include собирает промпт из частей. Путь промпта задаётся настройкой.
- **Флот специализированных профилей.** Добавлены профили: `github_researcher`, `code_mechanic`, `fork_merger`, `ci_verifier`, `git_committer`. Маршрутизация флота выбирает профиль по задаче.
- **Правила оркестратора.** Промпт оркестратора требует чистого дерева перед работой. Промпт требует явного одобрения пользователя перед задачами. Протокол отказов останавливает работу при повторной ошибке.

### Безопасность
- **Защита dot-файлов.** Система запрещает запись в агентские конфигурационные файлы без разрешения.
- **Проверка идентификаторов.** Система проверяет `task_id`, статус задачи и валидность изоляции при запуске субагента. Отмена задачи попадает в журнал аудита.

### Надёжность (Windows)
- **Обработка Sharing Violation.** Сканер worktree пропускает временные ошибки файловой системы. Атомарная замена файла повторяется при занятом файле.
- **Защита от паник в GUI.** `WndProc` перехватывает паники и очищает стек вызовов. Журнал пишет строки в непрерывный буфер. Исправлена блокировка при авторизации правки.

### CI и сборка
- **Конвейер релиза.** Добавлен workflow сборки релиза для macOS и Linux. Добавлена Windows-сборка. Раннер macOS переведён на `macos-15` с Xcode 16. Очистка диска удаляет неиспользуемые SDK.
- **Верификация агента в CI.** Workflow `agent_verify` запускает clippy и тесты на Windows. Настроен sccache и отключена инкрементальная сборка.

### Модели и окружение
- **Загрузка `.env` и подстановка переменных.** Настройки читают `.env`. Переменные раскрываются в идентификаторах моделей и аргументах MCP-серверов.
- **Устойчивость потока данных.** Ошибки сети апстрима обрабатываются типизированно. Ограничены объём выборки и защита от сжатия контекста. Ожидаемое сообщение сохраняется при стриминге. Сессии субагентов сохраняются и восстанавливаются.
